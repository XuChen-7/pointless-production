# 请勿停止生产

> 本设备没有用途。请保持运行。

一个用来打发时间的荒诞工业像素风网页原型。玩家通过操作第零号无用产品制造机，生产备用借口、便携式星期三和其他没有用途的东西，并逐渐发现机器似乎正在观察操作员。

## 在线体验

[打开《请勿停止生产》](https://zero-useless-machine.xuchen050324.chatgpt.site)

## 原型内容

- 随机无用产品与每日荒谬订单
- 时间方向拉杆、情绪温度旋钮和禁止触碰按钮
- 故障、拍打维修与诚恳道歉
- 产品仓库及两两回炉融合
- 浏览器本地进度保存与离线报告
- 随生产进度逐渐暴露的机器意识
- 可开关的像素音效

## 本地运行

```bash
npm install
npm run dev
```

生产构建：

```bash
npm run build
```
